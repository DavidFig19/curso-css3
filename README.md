# 🎨 Proyecto del Curso de CSS3 – Udemy

> Proyecto realizado como parte del curso **CSS3: Aprende CSS3 desde CERO con Ejercicios Prácticos**.  
Este repositorio contiene todas las prácticas, ejercicios y mini-proyectos desarrollados a lo largo del curso, demostrando los conocimientos adquiridos en diseño web con CSS3.

---

## 📘 Descripción General

Este proyecto reúne todo el material trabajado durante el curso, abarcando desde lo más básico hasta técnicas avanzadas para crear interfaces modernas, responsivas y bien estructuradas con **CSS3**.

Incluye ejercicios prácticos, experimentación con propiedades, layout modernos como **Flexbox** y **CSS Grid**, así como mini-proyectos completos.

El repositorio sirve como referencia personal, portafolio y documentación de aprendizaje.

---

## 📚 Contenido Aprendido en el Curso

El curso está compuesto por múltiples secciones que abarcan los siguientes temas:

### 🎯 **Fundamentos de CSS**
- Selectores básicos  
- Colores, bordes y fondos  
- Modelo de caja (Box Model)  
- Margen, padding y display  
- Posicionamiento básico y avanzado  

### 📐 **Medidas y Elementos**
- Unidades de medida en CSS3  
- Imágenes en CSS  
- Listas y estilos  
- Prácticas de texto y fondos  

### 🧩 **Selectores Avanzados**
- **Pseudoclases**  
- **Pseudoelementos**  

### 🏗 **Estructura y Layout**
- Posicionamiento de cajas  
- Variables en CSS  
- Responsive Design  
- Metodología **BEM**  

### 🧱 **Sistemas de Layout Modernos**
- **Flexbox** (sección completa con múltiples ejercicios)  
- Práctica: creación de **Cards**  
- Primer sitio web con Flexbox  
- **CSS Grid**  
- Práctica completa con Grid
